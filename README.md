# SupplyMate

**SupplyMate** — цифровая платформа для малого бизнеса, которая помогает контролировать остатки, прогнозировать дефицит, сравнивать поставщиков и автоматизировать закупки.

### Основные функции
- Учёт остатков товаров
- Автозаказы
- Сравнение поставщиков
- Прогноз спроса
- Личный кабинет
- Админ-панель

**Tech:** React + TypeScript + LocalStorage

Проект создан как MVP для **SERPIN Business Tournament**.
